# 第二批 SEO 修改：实测评测与排行榜

本轮依据上一轮确定的范围，先检查全球云、XSUS、拼好连三家试点，再将共用评测展示应用到全部九家实测机场，并完善排行榜的比较说明。没有改动未实测资料页的索引策略。

## 页面变化

- 每家实测页增加三条由记录派生的观察：采样时段与地区更新范围、地区历史下载代表值的差异、具体记录所附的服务体验差异。摘要区分代表记录与完整统计，不把 Speedtest 截图当作 ChatGPT 或流媒体体验验证。
- 四地区分别展示记录数、日期数、最近实际测试日期、逐日下载与上传中位数、状态分布及原始记录。图表以真实日期间隔绘点、统一从零起的速度轴，没有连成连续监测曲线，未采样日不补值。
- 关键截图选择最近带图记录、带图低速记录及跨日样本，保留完整原图比例、采样条件、日期与选择依据。共生成 27 张 WebP 缩略图，平均约 18KB，懒加载并保留原图链接。
- 九家实测页各有一张 1200×630 的 PNG 分享图，使用与正文相同的历史下载中位数和各地区最近日期，标明非实时速度。Article 与 OG 使用同一张图及相关描述。
- 实测页标题、摘要和首屏说明强调本站实测；商业资料概要仍保留在基本信息中。新增页内导航连接摘要、地区历史、评分、截图和原始记录。
- 排行榜保留综合排序与原有表格，新增九家比较卡，分别说明体验分、计分套餐、接入条件、设备限制和各地区最新记录。页面没有新增用户星级，也没有修改评分权重。

## 日期与数据边界

九家实测页与排行榜的实质编辑日期记录为 2026-10-13。实测页可见整理日期、Article/WebPage 与 sitemap 共用页面路径的编辑日期；原始测速、商业复核与 Dataset 日期保持独立。

135 条原始记录、机场商业字段、未实测资料库、交接清单及评分核心与本轮开始时逐字节一致。所有九家综合分保持不变。未知地区或同时命名两个地区的节点不会被猜测分配到图表；真实零值保留。各日中位数是展示统计，不替代现有评分。

新摘要是有限历史样本的事实整理，不能据此证明线路改善、长期在线率、全部运营商表现、未记录的平台解锁或精确响应时间。本文没有补造缺失条件，也没有采集新测速。

## 验证

- 28 项检查通过，其中 13 项新增汇总检查覆盖核验过滤、逐日与跨日权重、零值、地区歧义、最新记录、状态计数、证据类型、截图选择与输入不变性。
- 商业资料交接与数据审计通过；Astro 类型检查零错误、零警告，67 个 HTML 页面和 36 个静态图片端点构建成功。
- 66 个可索引 URL 与 sitemap 保持一致，图片端点不进入页面 sitemap；全站内部链接、锚点和引用图片没有断链，所有页面各一个 H1。
- 135 个原始记录锚点保留；新统计与截图入口可以显示并定位对应历史分页。
- 浏览器核对三家试点的日期与显示范围：XSUS 仅新加坡最新至 10-08，其他三地区仍为 09-23；拼好连最近测速仍为 09-23，不因正文编辑而变成新增测试。
- 320px 和 375px 下未见全页横向溢出，表格在自身容器内滚动，可聚焦并用方向键操作。截图正常加载、声明尺寸与原图比例一致；桌面四地区图表使用同一刻度。

本轮改动保存在本地工作区，未提交或发布。
